# FXEC First-Year Competency Portal — Launch Readiness Gate

Date: 26 September 2026

## Release blocker

The current Firestore rule for students/{id} allows a signed-in student to update their own document. Registration and approval already run through trusted Cloud Functions, so production should change this rule to allow client reads only and server/admin writes.

This must be corrected before full-cohort launch because otherwise a client could tamper with profile fields such as approval status or role.

## Required smoke test

1. Student registration with a dedicated test account.
2. Admin dashboard sees the pending student.
3. Admin approves the student.
4. Student signs in again and sees approved status.
5. Scheduled assessment opens only inside its configured window.
6. Assessment submission is accepted and scored server-side.
7. Result and reward points are generated by the server.
8. C competency journey loads and sequential activity unlocking works.
9. Correct competency activity answer awards XP; incorrect answer does not.
10. Admin can manage schedules/content and export results.

## Configuration gate

Verify in Firebase before launch:

- Vertex AI enabled.
- Cloud Text-to-Speech enabled.
- COMPILER_API_URL configured with HTTPS.
- COMPILER_API_TOKEN configured where required.
- AZURE_SPEECH_KEY and AZURE_SPEECH_REGION configured before pronunciation assessment is enabled.
- ZEPTOMAIL_CONFIG configured in Secret Manager if transactional email is required.
- Judge0-compatible compiler capacity tested for the expected student concurrency.

## Integrity requirements

- Assessment answer keys must never be returned to the browser.
- Hidden coding tests must remain server-side.
- Assessment scoring must remain server-side.
- Client must not be trusted for approval, reward points, or result fields.

Repository inspection does not constitute Firebase runtime/deployment verification. The portal should not be declared production-ready until the Firestore rule blocker and authenticated smoke test are both cleared.
