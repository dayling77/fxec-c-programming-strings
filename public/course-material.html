DAY 1 – Understanding Strings

Today's Learning Goal

By the end of Day 1, you should be able to:

  • Explain what a string is in C.
  • Understand character arrays.
  • Explain the null character \0.
  • Declare and initialize strings.
  • Read strings from the user.
  • Access characters using indexes.
  • Modify individual characters.

1. What is a String?

A string is a sequence of characters used to represent textual data.

For example: 

Jack

The individual characters are: 

J   a   c   k

In C, strings are represented using arrays of characters. 

char name[] = "Jack";

2. The Null Character

A C string ends with a special character called the null character. 

'\0'

Therefore: 

J   a   c   k   \0
Remember:

The null character tells C where the string ends.

3. String Size

"Jack" has four visible characters. But a C string also needs \0. 

J   a   c   k   \0

1   2   3   4    5

Therefore five positions are required.

4. Character Array 

char name[20];

This creates space for 20 characters.

A string can also be initialized directly: 

char name[] = "Jack";

5. Printing a String 

printf("%s", name);

The %s format specifier tells printf() that we are printing a string.

6. Accessing Individual Characters 

char name[] = "Jack";

printf("%c", name[0]);

Output: 

J

Remember that indexing starts from zero.

Index Character
0 J
1 a
2 c
3 k
4 \0

7. Reading a String 

char name[50];

scanf("%49s", name);

Notice that we do not use: 

&name

because the array expression is used as the address of its first element in this context.

8. Why scanf() Has a Limitation

Suppose the user enters: 

Jack Smith

With: 

scanf("%49s", name);

the first word is read because whitespace terminates the %s conversion.

9. Reading a Complete Line

char name[100];

fgets(
    name,
    sizeof(name),
    stdin
);

This is suitable when the input may contain spaces.

Important:

Do not use gets(). It was removed from the C standard because it cannot safely limit input length.

10. Modifying a Character 

char name[] = "Jack";

name[0] = 'L';

printf("%s", name);

Output: 

Lack

DAY 2 – String Library Functions

Today's Learning Goal

Today you will learn the four most commonly used C string functions:

  • strlen()
  • strcpy()
  • strcat()
  • strcmp()

1. The string.h Header File 

#include <string.h>

The standard string handling functions are declared in this header.

2. strlen() 

char word[] = "Computer";

printf("%zu", strlen(word));

Output: 

8

The null character is not included in the returned length.

3. strcpy() 

char source[] = "Programming";

char destination[50];

strcpy(destination, source);

The contents of source are copied to destination.

4. strcat() 

char first[50] = "Hello ";

char second[] = "World";

strcat(first, second);

printf("%s", first);

Output: 

Hello World

5. strcmp() 

if(strcmp(a,b) == 0)
{
    printf("Equal");
}

A return value of zero means that the strings are equal.

Function Purpose
strlen() Find string length
strcpy() Copy a string
strcat() Join strings
strcmp() Compare strings
Important:

The destination array used by strcpy() and strcat() must have enough capacity for the result including the terminating null character.

DAY 3 – Manual String Processing

Today's Learning Goal

Today you will learn how string functions work by implementing the basic operations yourself.

This is important for coding assessments because you should understand the algorithm rather than only memorizing library functions.

1. Manual String Length 

int stringLength(char str[])
{
    int count = 0;

    while(str[count] != '\0')
    {
        count++;
    }

    return count;
}

2. Manual String Copy 

void copyString(
    char destination[],
    char source[]
)
{
    int i = 0;

    while(source[i] != '\0')
    {
        destination[i] = source[i];

        i++;
    }

    destination[i] = '\0';
}

3. Manual String Comparison 

int compareStrings(
    char a[],
    char b[]
)
{
    int i = 0;

    while(
        a[i] != '\0' &&
        b[i] != '\0'
    )
    {
        if(a[i] != b[i])
        {
            return a[i] - b[i];
        }

        i++;
    }

    return a[i] - b[i];
}

4. Reverse a String

The two-pointer method is useful here. 

LEFT  →        ← RIGHT

H E L L O

Swap the characters and move the pointers toward the center. 

char temp;

temp = str[left];

str[left] = str[right];

str[right] = temp;

5. Removing Spaces 

void removeSpaces(char str[])
{
    int i;
    int j = 0;

    for(i = 0;        str[i] != '\0';
        i++)
    {
        if(str[i] != ' ')
        {
            str[j] = str[i];

            j++;
        }
    }

    str[j] = '\0';
}

6. Character Conversion 

if(
    str[i] >= 'a' &&
    str[i] <= 'z'
)
{
    str[i] =
        str[i] - 'a' + 'A';
}
Programming Pattern:

Many string algorithms follow this structure: 

Start
  ↓
Read character
  ↓
Check condition
  ↓
Process character
  ↓
Move to next character
  ↓
Stop at \0

Today's Learning Goal

Today you will learn how to analyse the information contained inside a string.

You will learn:

  • Character frequency
  • Repeating characters
  • Non-repeating characters
  • Vowels and consonants
  • Digits and special characters
  • Word counting
  • Longest word

1. Character Frequency

Consider: 

banana

The frequency is: 

b = 1
a = 3
n = 2

2. Frequency Array 

int frequency[256] = {0};

for(
    int i = 0;
    str[i] != '\0';
    i++
)
{
    frequency[
        (unsigned char)str[i]
    ]++;
}

3. Most Frequent Character 

int max = 0;

char result;

for(int i = 0; i < 256; i++)
{
    if(frequency[i] > max)
    {
        max = frequency[i];

        result = i;
    }
}

printf("%c", result);

4. First Non-Repeating Character

Consider: 

swiss

The frequencies are: 

s = 3
w = 1
i = 1

The first character with frequency 1 is: 

w

5. Count Vowels

if(
    str[i] == 'a' ||
    str[i] == 'e' ||
    str[i] == 'i' ||
    str[i] == 'o' ||
    str[i] == 'u'
)
{
    vowels++;
}

6. Character Classification 

if(
    str[i] >= 'A' &&
    str[i] <= 'Z'
)
{
    uppercase++;
}

else if(
    str[i] >= 'a' &&
    str[i] <= 'z'
)
{
    lowercase++;
}

else if(
    str[i] >= '0' &&
    str[i] <= '9'
)
{
    digits++;
}

else if(str[i] == ' ')
{
    spaces++;
}

else
{
    special++;
}

DAY 5 – Advanced String Problem Solving

Today's Learning Goal

Today you will combine the techniques learned during Days 1–4 to solve more challenging programming problems.

The focus is not memorizing code. The focus is recognising the correct algorithmic pattern.

1. Palindrome

A palindrome reads the same from both directions. 

madam
level
radar
civic

2. Palindrome Using Two Pointers 

int left = 0;

int right =
    strlen(str) - 1;

while(left < right)
{
    if(str[left] != str[right])
    {
        printf(
            "Not Palindrome"
        );

        return 0;
    }

    left++;

    right--;
}

printf("Palindrome");

3. Case-Insensitive Palindrome

Should: 

Madam

be treated as a palindrome?

If the problem says that case should be ignored, then yes. The algorithm must normalize the characters before comparison.

4. Palindrome Ignoring Spaces

An advanced problem may give: 

A man a plan a canal Panama

The program may need to ignore spaces and case.

5. Anagram

Two strings are anagrams when they contain the same characters with the same frequencies. 

listen
silent

These are anagrams.

6. Anagram Using Frequency Array 

int freq1[256] = {0};

int freq2[256] = {0};

for(
    int i = 0;
    str1[i] != '\0';
    i++
)
{
    freq1[
        (unsigned char)str1[i]
    ]++;
}

for(
    int i = 0;
    str2[i] != '\0';
    i++
)
{
    freq2[
        (unsigned char)str2[i]
    ]++;
}

for(int i = 0; i < 256; i++)
{
    if(freq1[i] != freq2[i])
    {
        printf(
            "Not Anagram"
        );

        return 0;
    }
}

printf("Anagram");

7. String Rotation

Consider: 

abcd

Rotations include: 

bcda
cdab
dabc

A common technique is to consider: 

abcdabcd

If the candidate string appears inside this doubled string, it can be a rotation of the original.

8. Remove Duplicate Characters

Given: 

programming

Try to produce a version that retains only the first occurrence of each character.

9. String Compression

Given: 

aaabbcccc

Produce: 

a3b2c4

This is a basic form of run-length encoding.

10. Subsequence

Consider: 

Main string:
abcdef

Candidate:
ace

The candidate is a subsequence because the characters occur in the same order.

11. Longest Substring Without Repeating Characters

Given: 

abcabcbb

One longest substring without repeating characters is: 

abc

Therefore the answer is: 

3
Advanced Thinking:

First solve this using a straightforward nested-loop approach. Then try to improve it using a frequency array. Finally, study the sliding-window technique.
